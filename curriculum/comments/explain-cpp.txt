Language Fundamentals & Core MechanicsC++ is a statically typed, compiled, multi-paradigm language developed by Bjarne Stroustrup as an extension of C.
The language compiles directly into native machine code, bypassing virtual machines to achieve near-zero runtime overhead.
Strongly typed languages like C++ enforce strict type checks during compilation to catch mismatches before execution.
The main function serves as the definitive entry point for execution in every standard C++ application.
Pointers store the exact memory addresses of variables, enabling direct manipulation of system hardware resources.
References act as immutable aliases to existing variables, preventing the overhead of copying data across scopes.
The stack memory allocation handles local variables automatically, operating on a fast last-in, first-out basis.
The heap memory allocation allows for dynamic runtime sizing but requires manual tracking to prevent leaks.
The raw pointer requires explicit deallocation using the delete keyword to free allocated heap memory safely.
Dangling pointers occur when code references a memory address that has already been deallocated by the system.
Memory leaks happen when heap allocations lose their pointers without returning the space to the operating system.
Undefined behavior represents code paths that violate standard rules, leaving the compiler free to generate unpredictable machine instructions.
Object-Oriented Programming (OOP) & StructureClasses define user-created blueprints containing both encapsulated data attributes and executable member functions.
Encapsulation hides the internal state of an object, exposing operations only through public interface methods.
The public access specifier makes class members accessible from any code context within the entire application.
The private access specifier restricts variable modification solely to methods defined inside the containing class.
The protected access specifier limits member accessibility to the base class and its derived child classes.
Constructors handle object initialization, establishing invariants and allocating required resources when an object is instantiated.
Destructors automatically clean up object resources, running immediately when an object goes out of scope.
